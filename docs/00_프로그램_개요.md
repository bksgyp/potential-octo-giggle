## 1. 프로그램 성격

- 인하대학교 창업지원단의 대표 학생창업 프로그램. 매년 상·하반기 운영되며 이번이 제16회.
- 우수한 아이디어와 아이템을 보유한 학생팀을 발굴하여 **창업 기초교육, 맞춤형 멘토링(BM 고도화, 브랜딩, IR 피칭), 시제품 제작비**를 지원해 아이템 구체화를 돕는 것이 목적. `[14회][15회]`
- 외부 브랜딩 전문사(더마인즈)가 11~12회에 멘토링 파트너로 참여한 이력이 있음. 브랜딩과 IR 피칭 역량이 평가와 교육의 한 축이라는 점 참고.

## 5. 제출 서류 `[양식]`

하나의 .docx 파일 안에 다음 4개 문서가 포함되어 있음.

1. **지원신청서** : 팀 정보, 사업아이템 한 줄 정의, 사업자등록 여부, 팀장 정보, 팀원 명단
2. **사업계획서** : 문제인식 / 실현가능성 / 성장전략 / 팀구성 4개 대분류, 총 11개 항목 + 비즈니스 모델 캔버스(필수)
3. **학생활동지원비 집행 계획서** : 150만원 한도, 세목·세세목·산출근거·추진시기·금액
4. **개인정보 수집·제공 동의서** : 팀장 서명

각 서류의 작성 항목은 [01_제출_체크리스트.md](01_제출_체크리스트.md) 참고.

## 6. 평가 관점 (추정)

직전 회차 공고에서 확인된 심사 기준은 **경쟁력, 실현가능성, 사업화 추진 전략, 창업 동기와 의지, 팀 구성**의 종합 평가.
사업계획서 목차가 곧 평가 항목이라고 보고, 아래 순서대로 배점이 걸려 있다고 가정하고 작성한다.

| 사업계획서 대분류 | 대응 평가 관점 |
| --- | --- |
| 1. 문제인식 | 창업 동기, 문제 정의의 명확성, 시장 규모 근거 |
| 2. 실현가능성 | 개발 로드맵의 구체성, 경쟁 분석과 차별화 |
| 3. 성장전략 | BM 캔버스 완성도, 자금 계획의 현실성, 시장 진입 전략 |
| 4. 팀구성 | 창업자 역량, 역할 분담, 시너지 |

정확한 배점표는 16회 공고에서 확인 후 갱신. `[확인필요]`
