## 1. 문제 정의: 왜 커플 "웰니스"인가

### 1.1 관찰되는 문제

1. **관계 문제는 상시적이지만, 개입 수단은 극단적으로 이분화되어 있다.**
   - 한쪽 끝: 아무것도 안 함(참거나 싸움) → 대부분의 커플
   - 다른 쪽 끝: 부부상담/심리상담(회당 5~10만 원, 예약·낙인·시간 부담) → 이미 관계가 심각하게 망가진 뒤
   - **그 사이의 "가볍고, 반복 가능하고, 저렴한 관리 수단"이 비어 있다.**

2. **기존 커플 앱은 "기록"에 머물러 있고 "개선"을 하지 않는다.**
   - 비트윈·썸원 등은 메신저 + 앨범 + 기념일 = *추억 저장소*
   - 저장소는 관계가 좋을 때만 열리고, 갈등 시점에는 아무 기능도 제공하지 않는다 → **가치 제공 시점과 통증 발생 시점의 불일치**

3. **관계 만족도는 개인 웰빙의 최상위 변수인데, 관리 대상으로 인식되지 않는다.**
   - 운동·수면·식단·명상은 "관리하는 것", 관계는 "타고나는 것"으로 취급됨
   - 멘탈케어 시장이 급성장하며 이 인식이 흔들리는 중 → **카테고리 전환의 타이밍**

### 1.2 문제 진술문 (한 문장)

> 헤어질 정도는 아니지만 반복적으로 같은 갈등을 겪는 20~30대 커플은, 상담을 받기엔 부담스럽고 혼자 참기엔 지치는 상태에서 **관계를 점검하고 개선할 저렴하고 반복 가능한 도구가 없다.**

## 2. 시장 분석

### 2.1 상위 시장 흐름

- **글로벌 멘탈케어 시장**: 2023년 약 2,326억 달러, 2028년 4,140억 달러 전망(CAGR 약 12%). 심리적 문제의 "디지털 셀프케어화"가 구조적 추세. ([머니투데이](https://news.mt.co.kr/mtview.php?no=2025062616543636338))
- **커플 관계 앱(Relationship Apps for Couples) 시장**: 2025년 기준 추정치가 조사기관별로 **8.5억 달러 ~ 20억 달러**로 2배 이상 벌어짐(CAGR 13~15%). ([Market Reports World](https://www.marketreportsworld.com/market-reports/relationship-apps-for-couples-market-14713991), [Business Research Insights](https://www.businessresearchinsights.com/market-reports/relationship-apps-for-couples-market-117629))
  - ⚠️ **주의**: 이 수치는 2차 리서치 벤더 리포트로, 발표 자료에서 단독 근거로 쓰면 심사위원에게 반박당하기 쉽다. **아래 2.2의 상향식(bottom-up) 추정을 메인으로 쓰고, 벤더 수치는 보조로만 인용할 것.**

### 2.2 국내 시장 상향식 추정 (발표용 메인 논리)

| 단계 | 산식 | 규모 |
|---|---|---|
| **TAM** | 국내 20~39세 인구 약 1,200만 명 × 연애/혼인 중 비율 약 40% ≒ 480만 명 ≒ **약 240만 쌍** × 커플당 연 ARPU 6만 원 | **약 1,400억 원/년** |
| **SAM** | 그중 "관계 개선에 돈을 쓸 의향이 있는" 층 20% ≒ 48만 쌍 | **약 290억 원/년** |
| **SOM (3년)** | SAM의 3~5% ≒ 1.5만~2.4만 쌍 | **약 9억~15억 원/년** |

> 검증 필요 수치: ① 20~39세 연애 중 비율(40%는 가정치 — 자체 설문으로 대체할 것) ② 커플당 연 ARPU 6만 원(월 4,900~9,900원 구독 가정)

### 2.3 인접 시장 신호

- **2025년 혼인 건수 24만 건, 전년 대비 +8.1%**, 30대 초반 구간에서 13% 이상 증가. 조혼인율 4.7건. ([국가데이터처](https://www.kostat.go.kr/board.es?mid=a10301010000&bid=204&act=view&list_no=444103))
  - → "결혼 인구 감소"라는 통념과 달리 **최근 3년 연속 혼인율 상승**. 혼전 관계 점검·신혼 프로그램 수요의 우호적 배경.
- **비대면 심리상담 플랫폼(마인드카페·트로스트 등)** 이 30분 5만 원대 가격으로 시장을 형성 → **가격 앵커가 이미 존재**. 커플 웰니스는 그 1/10 가격대에서 "예방·유지" 포지션을 잡을 수 있다.

### 3.3 전략적 결론

> **빈칸은 "한국어 + 커플 2인 단위 + 진단 기반 + 저가 구독"의 교차점이다.**
> 비트윈 사고로 국내 커플 앱의 신뢰·점유가 흔들린 지금이 진입 창(window)이다. 단, 그 창은 **딜라이트룸(알라미 운영사)이 리브랜딩으로 메우기 전까지**로, 길게 잡아 12~18개월로 본다.

## 5. 핵심 가설과 검증 설계

가장 위험한 가설부터 검증한다(Riskiest Assumption Test).

| # | 가설 | 위험도 | 검증 방법 | 성공 기준 |
|---|---|---|---|---|
| **H1** | 한쪽이 제안했을 때 **상대방도 설치·참여**한다 (양면 온보딩) | ★★★ | 랜딩+초대링크 프로토타입, 50명 배포 | 초대 발송 대비 **파트너 수락률 40% 이상** |
| **H2** | 커플이 관계 개선에 **월 5천~1만 원을 지불**한다 | ★★★ | 가격 제시 랜딩 A/B, 사전예약 결제(스마트스토어 등) | 방문→결제의사 클릭 **8% 이상**, 실결제 2% 이상 |
| **H3** | 진단 결과가 **행동 변화로 이어진다**(단순 재미 소비가 아님) | ★★☆ | 4주 파일럿 20쌍, 사전/사후 관계만족도 척도 | 만족도 지표 유의미 상승 + 4주 잔존 50% |
| **H4** | 이별해도 **개인 사용자로 잔존**한다 (churn 방어) | ★★☆ | 코호트 관찰 | 이별 코호트의 30일 잔존 20% 이상 |
| **H5** | 웨딩·기업 채널로 **B2B2C 유통**이 가능하다 | ★☆☆ | 웨딩플래너/HR 담당 5곳 인터뷰 | 파일럿 의향 2곳 확보 |

**H1이 무너지면 아이템 자체를 재설계해야 한다.** 커플 앱의 사망 원인 1순위는 언제나 "한 명만 쓰는 앱"이다.

## 6. 제품 컨셉

### 6.1 한 줄 정의

> **"관계에도 건강검진이 필요하다" — 2주에 한 번 우리 관계를 진단하고, 그 주에 할 행동 하나를 처방하는 커플 웰니스 앱.**

### 6.2 핵심 루프

```
① 각자 따로 응답 (2분, 5~7문항)
        ↓
② 두 사람 응답을 합쳐 관계 리포트 생성
   - 일치 영역 / 인식 격차(gap) 영역 시각화
        ↓
③ 격차가 가장 큰 1개 영역에 대해 "이번 주 액션" 1개 처방
   (예: "이번 주에 서로의 하루 중 가장 힘들었던 순간을 한 번 물어보기")
        ↓
④ 수행 체크 → 다음 회차 진단에 반영 → 변화 그래프 축적
```

**핵심 차별점은 ②의 "인식 격차"다.** 개인 웰니스 앱은 절대 만들 수 없고, 기록형 커플 앱은 만들 생각이 없는 데이터다. 두 사람의 응답 차이 자체가 우리만의 데이터 자산이 된다.

### 6.3 기능 우선순위 (MoSCoW)

| 구분 | 기능 |
|---|---|
| **Must** | 커플 연결(초대 코드), 격주 진단 문항, 인식 격차 리포트, 주간 액션 1개, 푸시 리마인더 |
| **Should** | 관계 만족도 추이 그래프, 갈등 주제 태깅, 대화 가이드 카드 |
| **Could** | AI 대화 코치(상황 입력 → 표현 제안), 커플 챌린지, 기념일 연동 |
| **Won't (v1)** | 메신저, 사진 앨범, 위치 공유 — **기록형 경쟁자와 정면충돌하는 기능은 v1에서 전부 배제** |

> 초기 팀이 가장 흔히 저지르는 실수: "커플 앱이니까 채팅도 있어야지". 채팅은 카카오톡을 이길 수 없고, 앨범은 비트윈 사고 이후 **책임만 크고 차별성은 없는 기능**이다.

### 6.4 콘텐츠·문항의 신뢰성 확보

- 관계 만족도 척도는 검증된 도구를 참고: RAS(Relationship Assessment Scale, 7문항), DAS-4, Gottman 연구의 4가지 위험 신호(비난·방어·경멸·담쌓기)
- **주의**: 검증 척도를 그대로 쓰면 저작권/사용허가 이슈가 있을 수 있다. **문항은 자체 제작하되 구성 개념(construct)만 차용**하고, 발표 자료에는 "학술 척도 기반 설계"로 표현하고 근거 문헌을 각주로 남길 것.

## 7. 수익 모델과 단위경제

### 7.1 모델

| 계층 | 내용 | 가격 |
|---|---|---|
| Free | 월 1회 진단 + 요약 리포트 | 0원 |
| **Plus (주력)** | 격주 진단, 전체 리포트, 액션 추천, 추이 그래프 | **커플당 월 5,900원 / 연 49,000원** |
| Deep | 분기 1회 심층 리포트, 전문가 상담 연계 쿠폰 | 커플당 19,900원/회 |
| B2B2C | 웨딩업체·기업 EAP 번들 | 쌍당 15,000~30,000원 |

> **"커플당 1구독"이 핵심.** 인당 과금은 두 사람이 각각 결제 결정을 내려야 해서 전환율이 절반 이하로 떨어진다. 결제는 한 명이, 혜택은 두 명이 받는 구조로 설계한다.

### 7.2 단위경제 시나리오 (보수적)

| 항목 | 가정 | 값 |
|---|---|---|
| 커플당 월 구독료 | | 5,900원 |
| 앱스토어 수수료 | 15~30% | -1,180원 (20% 가정) |
| 콘텐츠·인프라 원가 | | -500원 |
| **커플당 월 공헌이익** | | **약 4,220원** |
| 평균 구독 유지 기간 | 커플 앱 특성상 짧게 가정 | 6개월 |
| **LTV** | | **약 25,000원** |
| 허용 CAC (LTV/3) | | **약 8,300원** |

**시사점**: 허용 CAC 8,300원은 **퍼포먼스 광고로는 사실상 불가능한 수준**이다. 따라서 성장은 반드시 아래에 의존해야 한다.
1. **바이럴(K-factor)**: 제품 구조상 사용자 1명이 반드시 1명을 초대한다 → 초대 수락률만 높이면 유료 획득 비용이 사실상 절반
2. **콘텐츠 오가닉**: 인식 격차 리포트는 SNS 공유 소재로 강력함(단, 프라이버시 설계 필요)
3. **B2B2C 번들**: 웨딩·기업 채널은 CAC를 파트너가 부담

> 즉, **이 아이템은 광고비로 성장하는 모델이 아니라 바이럴 구조로 성장하는 모델이다.** 이 점을 IR에서 명확히 말해야 단위경제 질문을 방어할 수 있다.

## 8. 리스크 분석

| 리스크 | 심각도 | 내용 | 완화 전략 |
|---|---|---|---|
| **R1. 양면 온보딩 실패** | ★★★ | 한 명만 설치하면 제품이 성립하지 않음 | 초대 전 "혼자서도 되는 가치"(개인 관계 성향 리포트) 선제공 → 초대는 그 다음. 초대 메시지 문구를 제품이 대신 써줌 |
| **R2. 이별에 의한 구조적 이탈** | ★★★ | 커플 앱의 해지는 개인 앱보다 근본적 | ① 데이터는 개인 소유로 설계 ② 이별 후 "회복 모드"(개인 웰니스로 전환) 제공 ③ 재연애 시 재활성화 |
| **R3. 감정노동 비대칭** | ★★☆ | 통상 한쪽(주로 관계에 더 신경 쓰는 쪽)만 참여 → 상대는 압박감으로 이탈 | 응답 부담 최소화(2분), 미응답 시 상대에게 독촉 알림 금지, "점수 매기기"로 보이지 않게 문구 설계 |
| **R4. 데이터 민감성·신뢰** | ★★★ | 관계 갈등 데이터는 최고 수준 민감정보. **비트윈 사고로 이용자 경계심 최고조** | 백업·복구 정책 명문화, 최소 수집, 개인 응답 원문은 상대에게 비공개(집계만 공유) — **이것을 마케팅 메시지로 전면에 내세울 것** |
| **R5. 의료·상담 규제** | ★★☆ | 치료·진단 표현 시 의료법·정신건강복지법 이슈 | "진단" 대신 "체크인/점검", "치료" 표현 금지, 전문가 연계는 제휴 형태로 분리 |
| **R6. 재미 소비 후 이탈** | ★★☆ | MBTI형 콘텐츠로 소비되고 1회성 종료 | 첫 리포트에서 반드시 "다음 회차에 확인 가능한 변화 지표"를 약속 → 재방문 이유 생성 |
| **R7. 대기업 진입** | ★☆☆ | 딜라이트룸이 비트윈 리브랜딩으로 유사 기능 추가 | 속도 + 데이터(격차 데이터셋) 선점 + 특정 세그먼트(예비부부) 깊이 파기 |

## 9. 12주 실행 로드맵

| 주차 | 목표 | 산출물 | 게이트 |
|---|---|---|---|
| 1~2 | 문제 검증 | 커플 20쌍 심층 인터뷰, 설문 200명 | "반복 갈등" 문제 공감 70% 이상 |
| 3~4 | 솔루션 검증 | 랜딩 + 초대 플로우 프로토타입(노코드) | **H1: 파트너 수락률 40%** |
| 5~6 | 가격 검증 | 가격 A/B 랜딩, 사전예약 | **H2: 결제의사 8%** |
| 7~9 | MVP 개발 | 진단→격차 리포트→주간 액션 최소 루프 | 앱 배포(또는 웹앱) |
| 10~12 | 파일럿 | 20~30쌍 4주 운영, 사전/사후 측정 | **H3: 4주 잔존 50%, 만족도 상승** |
| 12 | IR | 데모데이 자료 | 지표 기반 스토리 완성 |

> **7주차 이전에 앱 개발을 시작하지 말 것.** H1이 깨지면 만든 코드가 전부 무의미해진다. 3~6주차는 노코드(폼 + 자동화 + 카카오톡 알림톡)로 충분히 검증 가능하다.

## 10. IR 핵심 메시지 (데모데이용 3문장)

1. **"관계 문제는 상시적인데, 해결책은 상담뿐이다."** — 예방 구간이 통째로 비어 있다.
2. **"우리는 두 사람의 인식 격차를 보여주고, 이번 주에 할 행동 하나를 준다."** — 기록형 커플 앱도, 개인 웰니스 앱도 만들 수 없는 데이터.

## 부록: 열린 질문

- 1차 타깃을 예비부부로 잡으면 시장은 작아지지만(연 24만 쌍) 지불의사와 유통 채널이 명확해진다. **작고 확실한 시장 vs 크고 모호한 시장** — 액셀러레이팅 기간(12주) 안에 검증 가능한 쪽은 전자다.
- 앱이 아니라 **카카오톡 채널 기반**으로 먼저 만들 수 있는가? 설치 장벽(R1)을 사실상 제거할 수 있어 H1 검증에 유리하다. 진지하게 검토할 가치가 있다.
- AI 코치를 v1에 넣을 것인가? 차별화 요소로 보이지만, H1/H3가 검증되기 전에는 원가와 복잡도만 늘린다. **v2 이후 권장.**
