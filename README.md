# 제16회 아랩 액셀러레이팅 프로그램 (2026-2학기)

인하대학교 창업지원단이 운영하는 **제16회 아랩(i-Startup Lab) 액셀러레이팅 프로그램** 참여를 위한
문서, 사업 아이템 검토, 진행 경과를 한곳에 모아 관리하는 저장소입니다.

## 현재 상태

| 항목 | 상태 |
| --- | --- |
| 프로그램 단계 | 지원 준비 (2026년 9월 접수) |
| 팀명 / 아이템 | 미정 (후보 2건 검토 중, [ideas/](ideas/README.md)) |
| 지원신청서 | 양식 확보, 초안 작성 전 |
| 사업계획서 | 템플릿 준비 완료, 초안 작성 전 |
| 집행 계획서 | 템플릿 준비 완료 (150만원 기준) |

세부 진행 상황은 [progress/LOG.md](progress/LOG.md)에서 관리합니다.

## 저장소 구조

```
.
├── README.md
├── docs/
│   ├── 00_프로그램_개요.md          # 프로그램 개요, 혜택, 일정, 평가 관점
│   ├── 01_제출_체크리스트.md        # 제출 서류별 작성 항목과 점검 목록
│   └── 02_작성_가이드.md            # 사업계획서 각 항목 작성 요령
├── application/
│   ├── original/                    # 창업지원단 배포 원본 양식 (수정 금지)
│   └── drafts/                      # 실제 제출용 초안 (Markdown으로 작성 후 양식에 옮김)
│       ├── 01_지원신청서.md
│       ├── 02_사업계획서.md
│       ├── 03_학생활동지원비_집행계획서.md
│       └── 04_개인정보_동의서.md
├── ideas/
│   ├── README.md                    # 아이디어 백로그, 선정 기준, 비교표
│   ├── _template.md                 # 아이디어 검토 템플릿
│   ├── 01_지하철_역별_데이트코스_추천.md
│   └── 02_그림일기_기반_데이트_다이어리.md
├── progress/
│   └── LOG.md                       # 날짜별 진행 기록
└── assets/                          # 이미지, 도식, 참고 자료
```

## 작업 규칙

- 원본 양식(`application/original/`)은 수정하지 않고, 초안은 `application/drafts/`에서 작성합니다.
- 최종 제출본(.docx)은 `application/submitted/`에 제출일 기준 파일명으로 보관합니다.
- 팀원 개인정보(연락처, 학번, 생년월일)는 저장소에 올리지 않습니다. 제출 직전 양식에만 기입합니다.
- 진행 상황이 바뀔 때마다 `progress/LOG.md`에 한 줄씩 기록합니다.
