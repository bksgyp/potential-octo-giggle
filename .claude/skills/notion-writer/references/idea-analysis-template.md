# 아이디어 분석 페이지 템플릿

여러 사업 아이디어(또는 제안, 기획안)를 한 페이지에 비교 분석할 때 쓰는 틀이다. 모든 항목은 아래 "항목 템플릿"을 한 글자도 빼지 않고 같은 순서로 채운다. 항목마다 소제목이 다르거나 일부 항목만 링크로 대체하면 사용자가 재작업을 요청한다.

## 페이지 구조

```
<callout color="gray_bg">
	**분석 기준일**: YYYY-MM-DD. 분석 대상과 건수.
	**분석 틀**: 평가 항목과 배점.
	**양식**: 모든 항목이 같은 순서로 작성되었다는 설명. 원문이 있으면 토글에 보존했다는 언급.
	**공통 원칙**: 추정 표시, 규제는 전문가 확인 필요.
</callout>
```

```
### 개요
- 문제: 누가 어떤 고통을 겪는가. 문서에 적힌 근거 수치가 있으면 포함.
- 솔루션: 무엇을 어떻게 제공하는가. 확장 계획이 있으면 여기에.
- 타겟: 지불자와 사용자를 구분해 적는다.
- 수익 모델: 문서에 없으면 "문서에 명시되지 않음"이라고 쓰고 추정을 덧붙인다.
- 현재 단계: 메모 / 슬라이드 / 사업계획서 / 목업 / 동작하는 제품 중 무엇인지와 빠진 것.
```

## 작성 시 확인 목록

- 항목 수와 종합 비교표 행 수, 세부 점수표 행 수가 같은가.
- 각 항목의 평가표 점수와 세부 점수표의 점수가 일치하는가.
- 모든 항목에 소제목 7개(기본 정보 표, 개요, 강점, 리스크와 약점, 검증해야 할 핵심 가설, 개선 제안, 평가)가 있는가.
- 개요의 다섯 줄(문제, 솔루션, 타겟, 수익 모델, 현재 단계)이 모든 항목에 있는가.
- "N건 중 가장 ~"처럼 건수를 언급한 문장이 현재 건수와 맞는가.
- 물결표, 대괄호, 세로줄 같은 이스케이프 대상 문자가 본문에 남아 있지 않은가.
