# 02. 그림일기 기반 데이트 다이어리

- 한 줄 정의(초안): 커플을 위한 그림일기 형식의 데이트 기록·감정 공유 앱
- 지원 구분: 서비스/앱/플랫폼
- 상태: 검토 중
- 노션 원문: https://app.notion.com/p/yup6786/3c2959f514e480788b35ed2042740acf (#2)

## 문제 (노션 원문 요약)
- 커플의 데이트를 아카이빙할 매체가 마땅히 없다. 클라우드나 갤러리 정도.
- 사진은 기억을 불러오지만, 같은 데이트에 대해 두 사람이 서로 다른 감정을 가질 수 있다. 그 차이를 기록하고 나눌 도구가 없다.

## 대상 유저
- 커플 (각자 기록)
- 친구들 (확장 시)

## 서비스 기획 (노션 원문 요약)
- 그림일기 형식으로 하루의 데이트를 기록.
  - 사진은 최대 N개, 직접 그린 그림도 가능.
  - 오늘의 감정을 1~5로 매기고, 둘의 평균을 제공.
  - N00자 이내의 글로 마무리.
- 같은 그림에 대해 각자 글을 작성. 본인 글을 쓴 뒤에만 상대 글을 열람 가능.
  - AI가 두 글을 합쳐 하나로 제공하는 기능 검토.
- 이용 약관에 "추후 데이트 코스 추천 서비스에 활용 가능" 명시 (아이디어 01과의 연결 고리).
- 일기이므로 위치가 아닌 날짜 기반으로 동작.
- 추가: "오늘의 한 컷". 하루에 의미 있는 단 한 장만 기록.

## 3개월 MVP (검토 의견)
- 범위: 커플 페어링 → 날짜별 일기 작성(사진 + 감정 점수 + 글) → 상호 열람 잠금 해제까지 동작하는 모바일 웹 또는 앱.
- AI 합성 글은 API 호출 한 번으로 구현 가능하므로 MVP에 포함해도 부담이 적다.
- 150만원 사용 예: 앱 디자인 외주, 서버·스토리지 이용료, AI API 비용, 사용자 테스트 모집.
- 필요 기술: 모바일 앱 또는 PWA, 이미지 저장, 인증·페어링. 외부 데이터 의존이 없어 01보다 구현 리스크가 낮다.

## 수익 모델
- 프리미엄 구독(저장 용량, AI 기능, 테마).
- 연말 포토북·인쇄물 제작 연계.
- 축적된 데이트 데이터를 바탕으로 한 추천 서비스(01)로 확장.

## 리스크와 미해결 질문
- 커플 앱(비트윈 등) 시장은 이미 경쟁자가 있다. "감정 점수 비교"와 "상호 열람 잠금"이 결정적 차별점인지 검증 필요.
- 사용자가 지속적으로 기록하게 만드는 동기가 약할 수 있다. 리텐션 장치(리마인더, 기념일 회고 등) 설계 필요.
- 개인 사진·감정 데이터를 다루므로 개인정보 처리 방침과 저장소 보안을 사업계획서에 명시해야 한다.
- "추후 추천 서비스에 활용" 약관은 데이터 활용 동의 범위를 명확히 해야 한다.
