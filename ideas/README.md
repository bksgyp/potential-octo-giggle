## 선정 기준

프로그램의 평가 관점(경쟁력, 실현가능성, 사업화 전략, 창업 의지, 팀 구성)과
제약 조건(150만원, 약 3개월, 학부생 팀)을 반영한 기준이다. 각 5점 만점.

| 기준 | 질문 |
| --- | --- |
| 문제의 명확성 | 누가 어떤 상황에서 겪는 문제인지 한 문장으로 말할 수 있는가 |
| 팀 적합성 | 팀이 직접 겪었거나 잘 아는 문제인가, 필요한 기술을 보유했는가 |
| 3개월 내 MVP | 150만원과 학기 중 시간으로 시연 가능한 시제품이 나오는가 |
| 시장 근거 | 시장 규모와 수요를 출처 있는 숫자로 뒷받침할 수 있는가 |
| 차별화 | 경쟁 제품 대비 빈 자리가 분명한가 |
| 수익 모델 | 누가 얼마를 왜 지불하는지 설명되는가 |

## 비교표

| 아이디어 | 문제 명확성 | 팀 적합성 | 3개월 MVP | 시장 근거 | 차별화 | 수익 모델 | 합계 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 01 지하철 데이트코스 | 4 | 미정 | 3 | 미정 | 3 | 3 | 13 + 미정 |
| 02 데이트 다이어리 | 3 | 미정 | 4 | 미정 | 3 | 3 | 13 + 미정 |

1차 잠정 점수는 노션 기획안만 보고 매긴 것이다. 팀 적합성은 팀 구성 확정 후, 시장 근거는 자료 조사 후 채운다.

## 1차 검토 의견

- **01 지하철 데이트코스**: 문제 정의가 구체적이고 수익 모델(업장 광고)이 분명하다. 다만 지도 앱과의 차별화 한 문장, 초기 스팟 데이터 확보, 릴스 연동의 API 제약이 걸림돌이다. MVP는 노선 1~2개로 좁혀야 3개월 안에 시연 가능하다.
- **02 데이트 다이어리**: 외부 데이터 의존이 없어 3개월 MVP 구현 리스크가 낮고, AI 글 합성이 발표에서 보여주기 좋다. 다만 기존 커플 앱과의 경쟁, 지속 기록 동기가 약점이다.
- 심사에서 "시장 규모 근거"와 "경쟁 제품 대비 차별화"를 요구하므로, 어느 쪽이든 커플 앱·데이트 관련 서비스 시장 자료 조사가 선행되어야 한다.
